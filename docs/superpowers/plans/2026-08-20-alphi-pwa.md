# Alphi Installable PWA Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make Alphi Business Agent installable as a branded PWA without offline or authenticated-data caching.

**Architecture:** Next.js App Router supplies the manifest and root metadata. A client-only component registers a minimal service worker that claims clients but never intercepts fetches or calls the Cache API; generated PNG icons package the approved logo for Android and Apple launchers.

**Tech Stack:** Next.js 16 App Router, React 19, TypeScript, Node.js static verification, browser Service Worker API, PowerShell `System.Drawing` for deterministic icon resizing.

## Global Constraints

- PWA is installable-only; no offline dashboard access, authenticated-page caching, agent/user-data caching, push notifications, background sync, custom install prompt, or offline fallback.
- Full name is `Alphi Business Agent`; short name is `Alphi`.
- Stable app ID and start URL are `/`; display is `standalone`.
- Background color is `#fbfbfc`; theme color is `#2c6b5c`.
- Icons are derived from `public/alphi-logo.jpg`: 180px Apple touch, 192px manifest, and 512px manifest PNG files.
- Do not change or stage `package-lock.json`.
- Do not perform visual browser testing.

- [ ] **Step 1: Write the failing verifier**

Create `scripts/verify-pwa.mjs` using Node built-ins. It must read `src/app/manifest.ts`, `src/app/layout.tsx`, `src/components/PwaRegistration.tsx`, `public/sw.js`, and `next.config.ts`; require the approved names, URLs, colors, display mode, icon paths, Apple metadata, `Viewport` theme color, `/sw.js` registration, `skipWaiting()`, `clients.claim()`, and no-cache worker headers. It must reject `caches.`, `caches[`, `addEventListener("fetch"`, and `addEventListener('fetch'` in the worker. For each icon, read PNG bytes 16 and 20 as big-endian dimensions and require `180x180`, `192x192`, or `512x512` as appropriate.

```js
import { existsSync, readFileSync } from "node:fs";
import { dirname, resolve } from "node:path";
import { fileURLToPath } from "node:url";

const root = resolve(dirname(fileURLToPath(import.meta.url)), "..");
const failures = [];
const read = (path) => {
  const absolute = resolve(root, path);
  if (!existsSync(absolute)) {
    failures.push(`${path} is missing`);
    return "";
  }
  return readFileSync(absolute, "utf8");
};
const requireTokens = (path, source, tokens) => {
  for (const token of tokens) {
    if (!source.includes(token)) failures.push(`${path} is missing ${token}`);
  }
};

const manifest = read("src/app/manifest.ts");
const layout = read("src/app/layout.tsx");
const registration = read("src/components/PwaRegistration.tsx");
const worker = read("public/sw.js");
const config = read("next.config.ts");

requireTokens("src/app/manifest.ts", manifest, [
  'name: branding.appName', 'short_name: "Alphi"', 'id: "/"',
  'start_url: "/"', 'display: "standalone"', 'background_color: "#fbfbfc"',
  'theme_color: "#2c6b5c"', 'src: "/icons/alphi-192.png"',
  'sizes: "192x192"', 'src: "/icons/alphi-512.png"', 'sizes: "512x512"',
]);
requireTokens("src/app/layout.tsx", layout, [
  'manifest: "/manifest.webmanifest"', "appleWebApp:", "capable: true",
  "title: branding.appName", 'statusBarStyle: "default"',
  'apple: "/icons/alphi-180.png"', 'themeColor: "#2c6b5c"', "<PwaRegistration />",
]);
requireTokens("src/components/PwaRegistration.tsx", registration, [
  '"use client"', '"serviceWorker" in navigator',
  'navigator.serviceWorker.register("/sw.js"', 'scope: "/"', 'updateViaCache: "none"',
]);
requireTokens("public/sw.js", worker, ["self.skipWaiting()", "self.clients.claim()"]);
for (const forbidden of ["caches.", "caches[", 'addEventListener("fetch"', "addEventListener('fetch'"]) {
  if (worker.includes(forbidden)) failures.push(`public/sw.js must not contain ${forbidden}`);
}
requireTokens("next.config.ts", config, [
  'source: "/sw.js"', 'key: "Content-Type"',
  'value: "application/javascript; charset=utf-8"', 'key: "Cache-Control"',
  'value: "no-cache, no-store, must-revalidate"',
]);

for (const [path, expected] of [["public/icons/alphi-180.png", 180], ["public/icons/alphi-192.png", 192], ["public/icons/alphi-512.png", 512]]) {
  const absolute = resolve(root, path);
  if (!existsSync(absolute)) {
    failures.push(`${path} is missing`);
    continue;
  }
  const png = readFileSync(absolute);
  const width = png.readUInt32BE(16);
  const height = png.readUInt32BE(20);
  if (width !== expected || height !== expected) failures.push(`${path} must be ${expected}x${expected}; found ${width}x${height}`);
}

if (failures.length) {
  console.error("PWA verification failed:");
  for (const failure of failures) console.error(`- ${failure}`);
  process.exitCode = 1;
} else {
  console.log("PWA verification passed.");
}
```

- [ ] **Step 2: Add a no-cache service worker and registration component**

Create `public/sw.js` with only install and activate listeners. The install listener calls `self.skipWaiting()`; the activate listener uses `event.waitUntil(self.clients.claim())`. Do not add a fetch listener or any Cache API call.

```js
self.addEventListener("install", () => {
  self.skipWaiting();
});

self.addEventListener("activate", (event) => {
  event.waitUntil(self.clients.claim());
});
```

Create `src/components/PwaRegistration.tsx` as a client component whose `useEffect` checks `"serviceWorker" in navigator`, calls `navigator.serviceWorker.register("/sw.js", { scope: "/", updateViaCache: "none" })`, logs registration failures with `console.error("Service worker registration failed:", error)`, and returns `null`.

```tsx
"use client";

import { useEffect } from "react";

export function PwaRegistration() {
  useEffect(() => {
    if (!("serviceWorker" in navigator)) return;
    navigator.serviceWorker
      .register("/sw.js", { scope: "/", updateViaCache: "none" })
      .catch((error: unknown) => console.error("Service worker registration failed:", error));
  }, []);

  return null;
}
```

- [ ] **Step 4: Generate exact launcher icons from the approved logo**

Use PowerShell `System.Drawing` to load `public/alphi-logo.jpg`, draw it with high-quality bicubic interpolation onto square 32-bit ARGB bitmaps of 180, 192, and 512 pixels, and save PNGs as `public/icons/alphi-180.png`, `public/icons/alphi-192.png`, and `public/icons/alphi-512.png`. Dispose every image, bitmap, and graphics object after saving.

```powershell
Add-Type -AssemblyName System.Drawing
New-Item -ItemType Directory -Force -Path public\icons | Out-Null
$source = [System.Drawing.Image]::FromFile((Resolve-Path public\alphi-logo.jpg))
foreach ($size in 180, 192, 512) {
  $bitmap = New-Object System.Drawing.Bitmap($size, $size, [System.Drawing.Imaging.PixelFormat]::Format32bppArgb)
  $graphics = [System.Drawing.Graphics]::FromImage($bitmap)
  $graphics.InterpolationMode = [System.Drawing.Drawing2D.InterpolationMode]::HighQualityBicubic
  $graphics.DrawImage($source, 0, 0, $size, $size)
  $bitmap.Save((Join-Path (Resolve-Path public\icons) "alphi-$size.png"), [System.Drawing.Imaging.ImageFormat]::Png)
  $graphics.Dispose()
  $bitmap.Dispose()
}
$source.Dispose()
```
